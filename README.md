# Data Cleaning & Visualization Project

A practical Python project demonstrating data preprocessing, exploratory data analysis, visualization, and data storytelling.

## Objectives

- Inspect raw data quality
- Handle missing values
- Remove duplicate records
- Detect numerical outliers using IQR
- Validate the cleaned dataset
- Perform exploratory data analysis
- Create meaningful visualizations
- Summarize key findings

## Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

## Dataset

The included customer purchase dataset contains:
- Customer ID
- Age
- Gender
- City
- Annual Income
- Product Category
- Purchase Amount
- Customer Rating
- Orders

The raw data intentionally contains common quality issues so the cleaning workflow can be demonstrated.

## Project Workflow

Raw Data → Quality Assessment → Cleaning → Validation → EDA → Visualization → Insights

## Visualizations

- Missing-value analysis
- Purchase distribution
- Product-category comparison
- City-level comparison
- Box plots
- Correlation heatmap
- Income vs purchase scatter plot

## How to Run

Open `data_cleaning_visualization.ipynb` in Jupyter Notebook, JupyterLab, Google Colab, or VS Code and run the cells from top to bottom.
