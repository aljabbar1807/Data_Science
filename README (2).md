# Exploratory Data Analysis (EDA) Project

## Overview
This project analyzes a sales dataset to uncover patterns, trends, relationships, and key influencing factors.

## Objectives
- Inspect and understand raw data
- Review missing values and duplicate records
- Generate statistical summaries
- Perform univariate, bivariate, and time-series analysis
- Study correlations and influencing factors
- Present findings in a structured report

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

## Dataset Features
- Order ID
- Order Date
- Region
- Sales Channel
- Product Category
- Customer Age
- Units Sold
- Unit Price
- Discount
- Customer Rating
- Revenue

## Analysis Included
- Data-quality assessment
- Missing-value visualization
- Revenue and age distributions
- Category, region, and channel comparisons
- Monthly revenue trend
- Correlation heatmap
- Scatter plot and box plots
- Business summary and key insights

## How to Run
Open `exploratory_data_analysis.ipynb` in Google Colab, Jupyter Notebook, JupyterLab, or VS Code and run all cells.

## Files
- `sales_eda_dataset.csv`

- `README.md`
- `requirements.txt`

## Learning Outcomes
This project demonstrates practical exploratory data analysis, statistical reasoning, visualization, and data storytelling.
